# Aparaitech Software - Terms & Conditions Portal

A legal and professional **Terms & Conditions Web Portal** for **Aparaitech Software** (Pune Headquarters), designed in modern SaaS layout with:

- **Typography:** Classic **Times New Roman** serif typography for an authentic, authoritative legal document aesthetic.
- **Alignment:** Clean, justified text alignment with structured bullet points and consistent margins.
- **Official Branding:** Uses the official **Aparaitech Software Company logo** (`/logo.jpg`).
- **Updated Date:** **1 May 2026**.
- **Two-Column Sticky Table of Contents (TOC)** with scroll-spy section tracking.
- **Direct WhatsApp Chat Integration:** Click-to-chat via `+91 9158852129` (https://wa.me/919158852129).
- **Floating WhatsApp Action Button** in bottom-right corner.
- **Dark & Light Mode Switcher**.
- **Print & PDF Support**.
- Clean presentation without extraneous forms.

---

## 📁 Repository Overview

- **`LIVE_PROJECT_TERMS_AND_CONDITIONS.md`**: Official terms and conditions document formatted for contract printing and archival.
- **`frontend/`**: Modern React 19 + Vite + Tailwind CSS application.
  - Public assets: `/logo.jpg` (Official Aparaitech Software Logo).

---

## 🚀 Getting Started

### Run Locally

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build for Production

```bash
cd frontend
npm run build
```
